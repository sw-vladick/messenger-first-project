### Репозиторій 2: Клієнт Unreal Engine 5

# Unreal Engine 5 Secure Messenger Client (C++ / UMG)

Клієнтська частина захищеного десктопного месенджера, розроблена повністю на **C++ та UMG в Unreal Engine 5**. Працює у зв'язці з кастомним багатопотоковим C++ TCP-сервером та використовує гібридне шифрування трафіку (RSA + AES-256).

> **Репозиторій сервера:** https://github.com/sw-vladick/messenger-server

## Основні можливості

* **Асинхронна мережева архітектура:**
  * Глобальне керування з'єднанням через підсистему `UNetworkManagerSubsystem` (`UGameInstanceSubsystem`).
  * Неблокуюче читання TCP-сокета в окремому фоновому потоці `FRunnable` (`DataReceiverRunnable`) із безпечною передачею даних у `GameThread` через `AsyncTask`.
  * Подієво-орієнтована маршрутизація відповідей сервера за допомогою динамічних делегатів у `UServerResponseRouter`.
* **Клієнтська криптографія (OpenSSL):**
  * Генерація сесійного ключа `AES-256` (`RAND_bytes`) при підключенні до сервера.
  * Шифрування сесійного ключа публічним RSA-ключем сервера (`RSA_PKCS1_OAEP_PADDING`) під час виконання Handshake.
  * Повне шифрування та дешифрування всіх JSON-команд алгоритмом `AES-256-CBC`.
* **Автентифікація та безпека в UI:**
  * Локальний вхід та реєстрація з клієнтською валідацією складності пароля та перемикачем видимості.
  * **Інтеграція Google OAuth 2.0:** вбудований віджет браузера (`UWebBrowser`), перехоплення редіректів, парсинг авторизаційних кодів та примусовий вибір акаунта (`prompt=select_account`).
  * **Двофакторне підтвердження пошти:** екран верифікації з таймером зворотного відліку (`FTimerHandle`) та обробкою блокувань.
* **Функціонал чату:**
  * Живий пошук користувачів та список останніх діалогів.
  * Миттєвий обмін повідомленнями, редагування відправлених повідомлень та індикація статусів прочитання (`✓` / `✓✓`).
  * Інтеграція нативного системного діалогу вибору файлів (`IDesktopPlatform::OpenFileDialog`) для відправки та скачування файлів частинами по 16 КБ.

## Архітектура класів

* **`UNetworkManagerSubsystem`:** Ядро мережевої взаємодії (підключення, Handshake, пакування команд, пошматкова відправка/прийом файлів).
* **`DataReceiverRunnable`:** Фоновий потік (`FRunnableThread`), що читає бінарні заголовки розміру пакета та передає JSON-відповіді у головний потік гри.
* **`UServerResponseRouter`:** Дешифрує корисне навантаження та розсилає події у віджети через `DECLARE_DYNAMIC_MULTICAST_DELEGATE`.
* **`UCryptoClient`:** Клієнтський криптографічний модуль на базі OpenSSL.
* **`ULoginWidget` / `UChatMessageWidget` / `UUserListItemWidget`:** C++ класи користувацького інтерфейсу (`BindWidget`), що керують усіма станами екранів через `UWidgetSwitcher`.

## Збірка та запуск

1. Склонуйте репозиторій та покладіть файл `public_key.pem` (відповідний до `private_key.pem` сервера) у кореневу папку проєкту.
2. Увімкніть плагін **Web Browser** у редакторі Unreal Engine (`Edit -> Plugins -> Web Browser`).
3. Переконайтеся, що у файлі `Messenger.Build.cs` підключені необхідні модулі:
   ```csharp
   PublicDependencyModuleNames.AddRange(new string[] { 
       "Core", "CoreUObject", "Engine", "InputCore", 
       "Sockets", "Networking", "Json", "JsonUtilities", 
       "UMG", "Slate", "SlateCore", "WebBrowserWidget", "WebBrowser", "OpenSSL" 
   });
Натисніть правою кнопкою миші на .uproject -> Generate Visual Studio project files, скомпілюйте проєкт у Visual Studio та запустіть редактор.
